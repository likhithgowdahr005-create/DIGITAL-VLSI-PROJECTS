# DIGITAL-VLSI-PROJECTS

This repository contains a collection of **Digital VLSI design projects** implemented using **Verilog HDL** and simulated using **Cadence nclaunch (Incisive/Xcelium)**.
These projects were developed as part of the **CodTech Internship Program** to strengthen understanding of digital hardware design and system architecture.

The projects demonstrate the design and implementation of fundamental digital hardware components, including arithmetic units, memory modules, processor pipelines, and digital signal processing blocks.

---

## Repository Structure

```text id="abx92k"
DIGITAL-VLSI-PROJECTS
│
├── TASK - 1 ALU
├── TASK - 2 RAM DESIGN
├── TASK - 3 PIPELINE
└── TASK - 4 DIGITAL FILTER
```

Each task folder contains the design files, testbench, simulation outputs, and reports related to that project.

---

## Tasks Included

### 🔹 TASK - 1: Arithmetic Logic Unit (ALU)

Design and implementation of an Arithmetic Logic Unit capable of performing arithmetic and logical operations.
The ALU is a fundamental building block of processors.

---

### 🔹 TASK - 2: RAM Design

Implementation of a Random Access Memory (RAM) module using Verilog HDL with controlled read and write operations.

---

### 🔹 TASK - 3: Pipeline Processor Design

Design of a pipelined processor architecture demonstrating instruction execution across multiple stages:

* Instruction Fetch
* Instruction Decode
* Execute
* Memory Access
* Write Back

---

### 🔹 TASK - 4: Digital Filter Design

Implementation of a digital filter architecture used in digital signal processing applications.
